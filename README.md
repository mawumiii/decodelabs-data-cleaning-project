# Decodelabs Data Cleaning Project

## 📌 Project Overview

This is my first data analytics project completed during my Decodelabs internship.

The main goal of this project was to clean and prepare a raw dataset for further analysis. Data cleaning is an important step in the data analytics process because the quality of the data directly affects the quality of the insights obtained from it.

## 🎯 Objectives

The project focused on:

- Understanding the structure of the dataset
- Identifying missing values
- Checking for duplicate records
- Identifying and handling data inconsistencies
- Correcting data types where necessary
- Removing or addressing unnecessary data
- Producing a clean dataset ready for analysis

## 🛠️ Tools Used

- Python
- Pandas
- Jupyter Notebook
- Excel

## 🔎 Data Cleaning Process

The following steps were performed during the project:

1. Loaded the dataset into Python using Pandas.
2. Inspected the dataset structure and columns.
3. Checked for missing values.
4. Identified duplicate records.
5. Reviewed data types and corrected them where necessary.
6. Checked for inconsistencies and unusual values.
7. Cleaned the dataset based on the identified issues.
8. Exported the cleaned dataset for further analysis.
